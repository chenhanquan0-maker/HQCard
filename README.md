# HQCard

一款用于**上下班打卡时间记录**的 Android 小工具。

## 项目目的

使用小米手机（实测 Redmi K40 / MIUI）日常通勤时，通过**双击电源键唤起小米钱包门卡**完成公司门禁/考勤刷卡。本 App 的核心目的就是：**在你双击电源键唤起刷卡界面、完成刷卡的那一刻，自动把日期时间记录下来**，形成一份可供回看的上下班打卡时间流水。

## 工作原理

### 主要方式：双击电源键唤起刷卡侦测（detector 模块）

1. 在小米手机上，双击电源键会唤起小米钱包的门卡界面（`com.miui.tsmclient/.ui.quick.DoubleClickActivity`）。
2. HQCard 通过一个**无障碍服务**（`WalletSwipeDetectorService`）订阅小米 TSM 客户端的窗口状态变化事件。
3. 当门卡界面出现的瞬间被观测到，App 立即记录当前时间作为一次刷卡事件（去抖窗口内只记一条）。

> 为什么用无障碍侦测？小米克隆门卡的交易发生在安全芯片（SE）中，系统不会通知第三方 App，普通 NFC 接口无法感知这次刷卡。因此采用"观测门卡界面被唤出"这一动作时刻作为打卡时间的近似记录。

该无障碍服务**不读取屏幕内容、不监听通知、不收集输入**，仅订阅窗口状态变化事件。

### 辅助方式：HCE 卡模拟（hce 模块）

对于主动向手机发送 SELECT AID 指令的读卡器，App 还内置了 HCE 主机卡模拟（虚拟卡 AID = `F04851434152443031`）：手机被读卡器选中时记录一次刷卡时间并返回 9000。老旧门禁（只读 UID、不发 SELECT）不会触发该路径。

## 功能

- 自动记录每次"唤起刷卡"的日期时间
- 主界面展示：NFC 状态、本机虚拟卡号、被刷卡记录列表（按时间倒序）
- 支持删除单条记录 / 清空全部记录
- 数据本地持久化（Room），写入由后台服务完成，不依赖界面存活

## 使用前提

- 小米手机（MIUI / HyperOS），已在**小米钱包**中开通/克隆公司门卡，并开启"双击电源键唤起刷卡"快捷方式
- 系统设置中为 HQCard 开启**无障碍服务**权限（用于侦测门卡界面唤出）
- HCE 方式需屏幕点亮，且读卡器会发送 SELECT AID 指令

## 技术栈

- Kotlin + Jetpack Compose + Room（本地持久化）
- 单 App 模块，按 MMDD（Markdown Module Driven Development）规范组织：`modules/` 下每个模块由 `docs/`（desc / interface / verify 契约）+ `impl/`（代码）组成

| 模块        | 职责                                                                 |
| ----------- | -------------------------------------------------------------------- |
| `detector`  | 无障碍服务侦测小米钱包门卡界面唤出（双击电源键），命中即记录时间     |
| `hce`       | HCE 卡模拟：被读卡器 SELECT 时记录刷卡时间                           |
| `record`    | Room 持久化刷卡事件：插入、倒序查询、删除、清空                      |
| `app_shell` | Compose UI + ViewModel：展示 NFC/侦测状态、虚拟卡号与记录列表        |
| `nfc`       | 前台读卡（v1 方案，已停用）；仅保留 NFC 可用性检测供 UI 状态指示     |

更多设计与实施细节见 [plan.md](plan.md) 与 [system.md](system.md)。
